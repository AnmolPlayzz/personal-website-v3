## 📌 Setup & Installation
1. Clone the repo:
   ```bash
   git clone https://github.com/anmolplayzz/personal-website-v3.git
   ```
2. Install dependencies:
   ```bash
   cd personal-website-v3
   npm install
   ```
3. Run the dev server:
   ```bash
   npm run dev
   ```
4. Open [localhost:3000](http://localhost:3000) and enjoy
